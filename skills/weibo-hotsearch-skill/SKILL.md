# 微博热搜 Skill

## 何时使用

当用户想要获取微博热搜榜时（例如「获取热搜前 10 条」「热搜前 5 条」「今日热搜」），使用本 skill。

## 使用步骤

1. 运行脚本拉取热搜列表，用 `--limit` 指定条数（支持任意条数）：

   ```bash
   python skills/weibo-hotsearch-skill/weibo_hotsearch.py --limit 10
   ```

2. 脚本返回 JSON 数组，每个元素包含：
   - `rank`：排名（从 1 开始）
   - `title`：标题
   - `hot_value`：热度值
   - `label`：标签（热 / 新 / 爆，可能为空）

3. 按 `rank`（排名）或 `hot_value`（热度）排序后，**对每一条热搜逐条总结热点内容**：
   - 若标题明确且你已知晓该事件，可直接给出 1-2 句准确总结；
   - 若为突发新闻或陌生话题，使用 WebSearch 搜索标题获取最新详情后，再给出准确总结。

4. 以 Markdown 列表输出，每条包含：排名 + 标题 + 热度 + 总结。

## 参数说明

- `--limit`：返回条数，默认 10（例如 `--limit 5` 表示前 5 条）。
- `--format`：`json`（默认，供程序解析）或 `text`（人类可读）。

## 说明

- 无需微博账号，使用微博 PC 端公开接口。
- 已过滤广告位与政务置顶条目，按热度排名返回。
